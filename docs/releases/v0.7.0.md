Snapshots now show human-readable creation dates. Mac and Windows default to
the user's current time zone and let you save a different zone, including UTC.
Pool snapshots appear newest first, with their original IDs retained.

The CLI accepts `--time-zone local`, `--time-zone UTC` or an IANA zone name.
Readable date columns are appended to existing snapshot output; `--json`
preserves the original UTC timestamps and identifiers.

The [Linux history test](https://mcchord.net/zfs-send-explore-test/LINUX-HISTORY-TESTING.md)
contains all 36 retained snapshots from a real Slide-backed Linux system,
spanning July 13–September 21, 2026. Independent restored-file hashes include
a package log with ten distinct versions.

Matching Mac and Windows app icons are included, with an automated check that
the Mac app works after being copied out of its download folder.

## macOS installation

Requires macOS 13 or later. Open the disk image for your Mac and drag
**ZFS Explore.app** to Applications. Copy `zfs-send-extract` to a writable folder
to use the CLI from Terminal. No ZFS installation or pool mount is required.

All Mac executables use hardened runtime, a timestamped **Developer ID
Application: Austin McChord (7PTN7E8EDS)** signature, and Apple notarization.
The app and DMG have stapled tickets. The CLI tarball contains the same notarized
executable but cannot carry a ticket on the bare binary; use the DMG when
preparing for offline use. macOS may still display its normal first-open
confirmation. Organization policies and OS/CPU compatibility requirements apply.

## Validation and limitations

The release workflow tests and builds Linux, Windows, Apple Silicon macOS and
Intel macOS. Mac signing checks include Apple's accepted notarization logs,
strict signature validation, stapled-ticket validation and Gatekeeper assessment.
The Linux history fixture passed 72 CLI restores across all 36 snapshots,
compared against independent filesystem reads. The Mac GUI restored the oldest
and newest package logs with matching hashes, and timezone changes preserved
the selected snapshot and file. Date tests cover daylight-saving transitions
and fractional UTC offsets. Timezone preferences change display, not snapshot
selectors or backup data.

Windows executables remain unsigned and may trigger SmartScreen. This remains
experimental recovery software. Sources are opened read-only; RAIDZ and pools
with multiple top-level vdevs are unsupported. Folder restore skips links and
special files and does not recreate filesystem metadata.
