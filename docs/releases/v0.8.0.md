Windows backups containing NTFS-compressed files now restore through the CLI,
Mac app and Windows app. Windows CBS logs and event logs previously reported an
unsupported-compression error; they now produce the original uncompressed bytes.
No extra driver, mount or conversion step is required.

The shared reader supports standard LZNT1 compression, mixed compressed/verbatim/
sparse units, fragmented files spanning multiple MFT records, and random reads
for disk images stored inside compressed NTFS files. Malformed compression data
fails without replacing an existing destination.

The [Windows history test](https://mcchord.net/zfs-send-explore-test/WINDOWS-HISTORY-TESTING.md)
contains all 30 retained snapshots of a real Windows 11 Slide backup, July13–Sep21.
It includes different versions of compressed CBS and event logs to restore.

## macOS installation

Requires macOS 13 or later. Open the disk image for your Mac and drag
**ZFS Explore.app** to Applications. Copy `zfs-send-extract` to a writable folder
to use the CLI from Terminal. No ZFS installation or pool mount is required.

All Mac executables use hardened runtime, a timestamped **Developer ID
Application: Austin McChord (7PTN7E8EDS)** signature, and Apple notarization.
The app and DMG have stapled tickets. The CLI tarball contains the same notarized
executable but cannot carry a ticket on the bare binary; use the DMG when
preparing for offline use. macOS may still display its normal first-open
confirmation. Organization policies and OS/CPU compatibility requirements apply.

## Validation and limitations

Ninety restores from all 30 Windows snapshots match independent OpenZFS/ntfs-3g
reads: win.ini, CBS.log and System.evtx. Synthetic tests cover mixed unit types,
fragmented attribute lists, random ranges, resident/empty files, nested FAT disk
images, truncated/corrupt chunks and unchanged destinations on failure.
The suite runs on native Linux, Windows, Apple Silicon and Intel macOS CI.

Standard NTFS LZNT1 compression with 16-cluster units and 512–4096-byte clusters
is supported. EFS encryption and WOF/CompactOS compression remain unsupported.
Windows executables remain unsigned. Sources stay read-only; RAIDZ and pools
with multiple top-level vdevs remain unsupported. Existing v0.7.0 downloads are
retained for rollback.
